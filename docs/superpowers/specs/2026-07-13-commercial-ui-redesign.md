# 玄机 AI 工作台 — 商业化界面重设计规格书

**日期**: 2026-07-13
**版本**: v1.0
**定位**: 企业级 AI 工作台（对标 Notion / Linear / Figma）
**风格**: 精准克制 + 品牌温度（深蓝专业色系）

---

## 1. 品牌标识系统

### 1.1 Logo 重设计

- **图标**: 基于"玄"字几何解构的抽象符号——三条水平线 + 一条垂直连接线，SVG 实现，线条 2px，圆角端点
- **尺寸**: 22×22px（侧边栏），40×40px（登录页）
- **品牌色**: `#4F6EF7`（略偏紫的蓝），辅助强调色 `#7C5CFC`
- **品牌渐变**: `linear-gradient(135deg, #4F6EF7 0%, #7C5CFC 100%)`

### 1.2 品牌字标

- 侧边栏展开态: "玄机" (16px, font-weight 600) + 副标 "AI Workspace"
- 收起态: 仅显示几何图标
- 版本标识: "PRO" 蓝色胶囊标签 (9px)，位于品牌名下方

### 1.3 色彩系统升级

| 变量 | 当前值 | 新值 |
|---|---|---|
| `--brand-500` | `#3B82F6` | `#4F6EF7` |
| `--brand-600` | `#2563EB` | `#3D5CE5` |
| `--brand-accent` | N/A | `#7C5CFC` |
| `--gradient-brand` | 纯蓝渐变 | `#4F6EF7 → #7C5CFC` |
| `--sidebar-bg` | `#1E3A5F` | `#0B1222` |
| `--gradient-sidebar` | 双色渐变 | 纯色 `#0B1222` |
| `--sidebar-active` | `rgba(59,130,246,0.08)` | `rgba(79,110,247,0.15)` |
| `--sidebar-hover` | `rgba(255,255,255,0.06)` | `rgba(79,110,247,0.12)` |

## 2. 侧边栏重设计

### 2.1 结构布局（从上到下）

1. **品牌区**: Logo 图标 + "玄机" 文字 + "PRO" 标签 + 分割线
2. **新建任务按钮**: 半透明蓝紫渐变 + 柔和呼吸光效
3. **导航分组**: "工作"组（工作台、任务）+ "工具"组（技能、搜索），带分组标题
4. **最近任务**: 滚动区域，显示最近5个会话
5. **折叠按钮**: 居中小圆按钮
6. **用户面板**: 胶囊卡片式，带在线状态指示 + PRO 会员标识

### 2.2 品牌区规格

- **收起态**: 仅几何 Logo 图标 (44×44px)，居中
- **展开态**: 图标 + "玄机" (16px/600w) + "AI Workspace" (11px/rgba(255,255,255,0.45)) + "PRO" 胶囊
- **分割线**: 1px `rgba(255,255,255,0.06)`

### 2.3 新建任务按钮

- **背景**: `rgba(79,110,247,0.2)` + 1px `rgba(79,110,247,0.4)` 边框
- **悬停**: `rgba(79,110,247,0.35)` + 品牌渐变发光
- **呼吸光**: `rgba(79,110,247,0.15)` ↔ `rgba(79,110,247,0.25)`（收敛版）
- **文字**: "+" 图标 + "新建任务"

### 2.4 导航项

- **激活态**: `background: rgba(79,110,247,0.15)` + 纯白图标和文字（取消 border-left 指示器）
- **图标**: 统一单色系（白/半透明白），取消 iconColor 差异
- **分类标题**: 10px, uppercase, letter-spacing 1px, `rgba(255,255,255,0.35)`
- **尺寸**: 高度 40px（从 44px 缩减），间距更紧凑
- **悬停**: 图标微右移 2px + `rgba(79,110,247,0.12)` 背景

### 2.5 用户面板

- **样式**: 胶囊卡片，`border-radius: 12px`，`background: rgba(255,255,255,0.06)`
- **头像**: 保留圆形 + 绿色在线状态点 (8px, `#10B981`)
- **文字**: 用户名 + "PRO 会员"（替换"用户"）
- **交互**: 点击展开菜单（取消独立设置齿轮按钮）

---

## 3. 顶部导航栏

### 3.1 非首页视图

- 背景: `var(--bg-primary)`（与内容区同色）
- **取消底部边框**，用 `shadow-xs` 替代
- 面包屑: "/" 分隔符（替代 ">"），字色更淡
- **AI 状态指示器**: 小绿点 + "AI Ready" (12px)
- 通知 + 设置按钮保留，图标统一

### 3.2 首页视图

- 保持当前布局但取消边框
- 搜索框改为**图标触发式**（点击弹出全宽搜索面板）
- Tab 标签: 激活态用 2px 蓝色下划线指示器（替代背景色）

---

## 4. 首页 Dashboard

### 4.1 布局（三区域）

1. **问候头**: 左侧问候语 + 右侧统计数字（平铺，非 Hero Banner）
2. **对话输入栏**: 居中浮动，品牌渐变发送按钮，引导用户开始对话
3. **快捷操作**: 4列紧凑图标卡片（扁平化，去掉描述文字）
4. **最近任务**: 卡片列表 + "查看全部" 链接

### 4.2 关键变化

- **取消 Hero Banner**（紫色渐变横幅）
- **对话输入栏上移到首页中央**（核心行为引导）
- **快捷操作卡片扁平化**: 图标 + 标题即可
- **最近任务**: 增加左侧彩色标记线

---

## 5. 输入栏 + 对话界面

### 5.1 统一输入栏

- **样式**: 浮动胶囊式，`border-radius: 16px`，`shadow-lg` 底部阴影
- **背景**: `var(--bg-secondary)` + 1px `var(--border-light)` 边框
- **发送按钮**: 品牌渐变色圆形按钮
- **占位符**: "描述你的任务或问题…"

### 5.2 消息气泡

- **用户消息**: 品牌蓝紫渐变 `#4F6EF7 → #6366F1`
- **AI 消息**: 白色背景 + 品牌渐变左侧竖线
- **AI 头像**: 小型 Logo 图标 (16px)
- **新消息动画**: 从底部滑入 + 淡入

### 5.3 会话上下文栏

- 高度: 36px → 44px
- 左侧: 标题 + 状态胶囊
- 右侧: 模型选择器（下拉选择器）
- 背景: `var(--bg-tertiary)` 浅灰

## 6. 全局微交互

| 交互 | 当前 | 新方案 |
|---|---|---|
| 页面切换 | fadeInUp 360ms | fadeInUp 200ms |
| 导航项悬停 | 背景变亮 | 图标微右移 2px + 背景渐变 |
| 按钮点击 | 无反馈 | `scale(0.98)` + 120ms |
| 消息出现 | 无动画 | 底部滑入 + 淡入 |
| 侧边栏折叠 | 宽度动画 | 增加内容淡出 |
