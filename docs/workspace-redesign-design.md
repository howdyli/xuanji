# 工作台界面渐进统一重设计方案

> 方案 A · 2026-05-29 · 已通过逐节评审

## 1. 概述

### 1.1 目标
在保持现有暖色米灰 + 紫色强调色设计系统的基础上，将工作台从"聊天式交互"升级为"工作流驱动型工作台"，解决三个核心痛点：
1. 聊天界面太单调——缺乏结构化输出、任务状态、进度跟踪
2. 首页与对话割裂——两个独立页面，切换生硬
3. 交互体验不流畅——右侧面板、工具栏、技能选择交互粗糙

### 1.2 设计原则
- **延续现有风格**：暖色米灰背景 `#f5f4f0`、紫色强调 `#5a4fcf`、Outfit 字体
- **渐进统一**：DashboardView 和 ChatView 共享外壳组件，内容区动态过渡
- **结构化输出**：AI 回复根据内容类型自动分类展示（卡片/表格/状态指示）
- **交互流畅**：过渡动画 280ms ease-out，操作反馈即时

### 1.3 涉及文件
| 文件 | 改动类型 |
|------|---------|
| `frontend/src/App.tsx` | 重大重构——新增 UnifiedWorkspace、拆分 DashboardHome/ChatMessages/UnifiedInputBar |
| `frontend/src/App.css` | 新增过渡动画、卡片化气泡、工具调用条样式 |

## 2. 整体架构与视图过渡

### 2.1 组件架构

```
<main>
  <DashboardTopBar />          ← 共享，始终显示
  <UnifiedWorkspace>           ← 新容器组件
    <ContentArea>              ← 根据 isEmpty 动态渲染
      {isEmpty ? <DashboardHome /> : <ChatMessages />}
    </ContentArea>
    <UnifiedInputBar />        ← 共享输入区
  </UnifiedWorkspace>
</main>
```

### 2.2 过渡机制

- **首页 → 对话**：用户在输入区发送消息后，输入区向下滑动到底部固定位置（280ms ease-out），上方 Dashboard 内容执行 `opacity: 0 + translateY(-20px)` 淡出，同时消息列表 `opacity: 1 + translateY(0)` 淡入，会话上下文栏从顶部滑入。
- **对话 → 首页**（新建任务）：上述动画逆序执行，消息列表淡出，Dashboard 内容淡入。
- **状态驱动**：通过 `messages.length === 0 && !historyLoading` 判断 isEmpty 状态，无需额外状态变量。

### 2.3 替代方案
不再使用 `activeNav === 'assistant' && messages.length === 0` 分支判断显示哪个视图，统一由 `UnifiedWorkspace` 组件内部管理过渡。

## 3. 统一输入区（UnifiedInputBar）

### 3.1 布局

```
┌─────────────────────────────────────────────┐
│ [实景沙箱] [Chat+] [Auto] [技能]  ← 模式标签 │
├─────────────────────────────────────────────┤
│  输入区域（textarea，自适应高度 40-200px）    │
├─────────────────────────────────────────────┤
│ [📎附件] [@专家] [📊数据源]    [↑ 发送]     │
└─────────────────────────────────────────────┘
```

### 3.2 状态差异

| 属性 | 首页状态 | 对话状态 |
|------|---------|---------|
| 位置 | 内容区中部（Bento 网格上方） | 内容区底部固定 |
| 圆角 | `rounded-[18px]` | `rounded-[16px]` |
| placeholder | "输入任务描述，例如：帮我分析 Q3 销售数据…" | "继续对话，或输入 / 调用指令…" |
| 额外工具 | — | +技能按钮 |
| 发送按钮 | 紫色圆形 ↑ 箭头 | 同左 |

### 3.3 模式标签
- 默认选中"实景沙箱"，标签高亮（白底 + shadow-sm）
- 其他标签灰色文字，hover 变深色
- 背景 `bg-[#f0efe9]`，内边距 `p-[3px]`，圆角 `rounded-[6px]`

### 3.4 快捷指令
- 对话状态下，输入 `/` 触发指令建议浮层
- 浮层显示 6 个预定义指令（日报生成、代码审查、全文翻译、会议纪要、数据分析、周报汇总）
- 选择后自动填充到输入框并发送

### 3.5 发送反馈
- 按钮点击时 `scale(0.95)` 按压效果（150ms）
- 发送后按钮短暂显示 ✓ 图标（200ms）再恢复箭头

## 4. 对话视图升级（ChatMessages）

### 4.1 会话上下文栏

对话状态时消息列表上方新增上下文栏（高度 36px）：

```
┌──────────────────────────────────────────────────┐
│ 📋 Q2 财务报告分析    ● 进行中   灵享妙语 Pro    │
└──────────────────────────────────────────────────┘
```

- **标题**：从 `session.title` 获取，点击可编辑（inline edit）
- **状态指示**：`● 进行中`（绿色 `#2d9e6b`）/ `● 已完成`（灰色 `#9b9892`）
- **模型标签**：显示当前模型名称，点击打开右侧 ConfigDrawer
- **样式**：`bg-white border-b border-[rgba(0,0,0,0.08)] px-5`，字号 12px

### 4.2 消息气泡升级

**用户消息**：
- 统一为 `bg-[var(--accent)]` 紫底白字，右对齐
- 圆角 `rounded-2xl rounded-tr-sm`
- 取代之前的橙色渐变（`from-orange-300 to-pink-400`）

**AI 消息**：
- 保持白色背景 + 左侧紫色渐变条（`msg-bubble-ai`）
- Markdown 渲染保持不变
- 增加内容类型自动分类：
  - **普通文本**：保持现有渲染
  - **含表格/列表**：自动包裹在卡片容器中，带轻量标题栏
  - **含任务结果**：增加状态指示前缀（✅/⏳/❌）

### 4.3 工具调用可视化

当 AI 调用技能/工具时，在消息流中插入"工具调用条"：

```
┌───────────────────────────────────┐
│ 🔍 百度搜索 · 已返回 5 条结果   ▼ │
└───────────────────────────────────┘
```

- 显示工具名称 + 状态摘要
- 可点击展开查看原始输入/输出（JSON 折叠面板）
- 样式：`bg-[#f0efe9] border border-[rgba(0,0,0,0.08)] rounded-[10px] px-3 py-2`
- 字号 11px，折叠面板使用 `<details>` 元素

**实现注意**：工具调用信息需从 AI 回复内容中解析，当前后端返回的 reply 中可能包含工具调用标记。如后端暂不支持结构化返回，先以文字提示形式展示（如"正在搜索…"）。

### 4.4 会话摘要横幅

当对话超过 10 条消息时，在消息列表顶部显示摘要横幅：

```
┌──────────────────────────────────────────────┐
│ 📝 本次会话已完成 3 项任务，生成 2 份文档     │
│ [查看详细摘要]                                │
└──────────────────────────────────────────────┘
```

- 统计信息从消息内容中简单提取（包含文件路径 = 生成文档，包含"完成" = 完成任务）
- "查看详细摘要"点击后展开完整列表
- 样式：`bg-[var(--accent-light)] border border-[rgba(90,79,207,0.15)] rounded-[10px] p-3`

### 4.5 加载状态改进

AI 回复等待时，替代现有三点弹跳动画：

```
┌────────────────────────────────┐
│ 玄  💭 思考中…                 │
└────────────────────────────────┘
```

- 显示"思考中…"文字 + 缓慢脉冲动画
- 如果检测到工具调用，切换为"🔍 搜索中…" / "📄 生成文档中…"等状态文字

## 5. 首页仪表盘优化（DashboardHome）

### 5.1 欢迎区
- 保持现有设计：动态问候 + 用户名 + 星期 + 引导语
- 无改动

### 5.2 统计卡片
- 保持现有 4 列卡片布局
- 新增 hover tooltip："点击查看详情"（11px 灰色提示）
- 卡片间距和尺寸不变

### 5.3 快捷操作区
- 保持 4 个快捷操作卡片
- **增强点击反馈**：点击后卡片短暂高亮（`bg-[var(--accent-light)]` 闪烁 200ms），然后过渡到对话状态
- **"自定义"按钮**：点击打开配置弹窗，支持增删排序（本期实现入口，弹窗内容后续迭代）

### 5.4 Bento 网格
- **最近对话**：从实际 `sessions` state 获取数据，显示真实会话标题和时间（替代硬编码 mock）
- **系统状态/本周趋势/快捷指令/今日时间线**：保持现有设计
- **快捷指令 chip**：点击后填充到 UnifiedInputBar 并发送

## 6. 右侧抽屉优化（ConfigDrawer）

### 6.1 模型卡片
- 选中时增加紫色边框 `border-[#5a4fcf]` + 浅紫背景 `bg-[#eeedf9]`
- 选中切换时增加背景脉冲动画（200ms）
- 新增模型能力标签 chip（如 `推理` `代码` `长文`），使用 10px 字号 + 对应色彩

### 6.2 常用技能
- 按使用频率排序（前端维护 frequency state），前 3 个加星标 `★`
- 选中/取消时增加微动画（scale 0.95 → 1，150ms）

### 6.3 使用技巧
- 改为图标 + 短句卡片式，每条一行：
  ```
  @  → @数据分析师 帮你分析数据
  #  → #文件 快速引用知识库文档
  /  → /report 一键生成日报
  ```
- 卡片样式：`bg-[#f0efe9] rounded-[8px] p-2.5`，图标用紫色强调

## 7. 顶栏与侧边栏微调

### 7.1 顶栏
- 通知铃铛增加未读数 badge（红色圆形，内显数字，max 9+）
- 模型标签点击同步打开右侧抽屉

### 7.2 侧边栏
- 搜索增强：搜索结果支持跳转到对应对话（本期保持现有功能不变）

### 7.3 全局交互打磨

| 交互 | 改进 |
|------|------|
| 发送按钮 | 点击 `scale(0.95)` 按压反馈 |
| 空状态 | 对话清空后平滑回到首页，`view-enter` 淡入 |
| 快捷键 | `Ctrl/Cmd + K` 聚焦输入框，`Ctrl/Cmd + N` 新建任务 |

## 8. 不在本期范围

以下明确不在本期实现范围内：
- 多标签页工作台（方案 C）
- 右侧面板改为固定侧边（方案 B）
- 后端 API 改动
- 暗色模式适配（现有主题系统不受影响）
- 移动端响应式布局重构（保持现有断点逻辑）
- "自定义"快捷操作的完整配置弹窗（仅实现入口按钮）
