### 阶段 1: CSS 设计系统升级（App.css）

**目标**: 更新全部 CSS 变量和基础样式，为后续组件改造奠定基础。

**文件**: `frontend/src/App.css`

**具体改动**:
1. 在 `:root` 中新增品牌变量：
   - `--brand-500: #4F6EF7`、`--brand-600: #3D5CE5`、`--brand-accent: #7C5CFC`
   - `--gradient-brand: linear-gradient(135deg, #4F6EF7, #7C5CFC)`
   - `--sidebar-bg: #0B1222`、`--sidebar-text: rgba(255,255,255,0.65)`、`--sidebar-text-active: #FFFFFF`
   - `--sidebar-hover: rgba(79,110,247,0.12)`、`--sidebar-active: rgba(79,110,247,0.15)`
   - `--sidebar-section-label: rgba(255,255,255,0.35)`
2. 更新 `--gradient-sidebar` 为纯色 `var(--sidebar-bg)`
3. 更新 `--primary-500` ~ `--primary-900` 为新品牌色值
4. 更新 `.sidebar` 背景为 `var(--sidebar-bg)`，取消渐变
5. 重写 `.sidebar-logo` 样式（增加品牌文字区域支持）
6. 重写 `.sidebar-nav-item` 及 `.sidebar-nav-item.active`（取消 border-left，改用背景色激活态）
7. 更新 `.sidebar-nav-item:hover` 为品牌色半透明背景
8. 新增 `.sidebar-section-title` 样式（分组标题）
9. 更新 `.sidebar-new-task-btn` 呼吸动画为新品牌色
10. 新增按钮点击微交互: `.btn-press:active { transform: scale(0.98) }`
11. 新增消息滑入动画: `@keyframes msgSlideIn { from { opacity:0; transform: translateY(8px) } }`
12. 更新 `.msg-bubble-user` 渐变色为品牌蓝紫色
13. 更新 `.msg-bubble-assistant::before` 为品牌渐变
14. 新增导航项悬停图标右移动画: `.sidebar-nav-item:hover svg { transform: translateX(2px) }`
15. 更新 `--duration-slow` 相关动画时间为更紧凑的 200ms
16. 更新 `.hero-banner` 相关样式（后续组件会移除，但保持兼容）
17. 新增 `.tab-button.active` 下划线指示器样式（替代背景色）

## 验证计划

- 每个阶段完成后启动前端 dev server 验证
- 使用 Browser agent 进行 E2E 视觉验证：侧边栏展开/收起、导航切换、新建任务、首页布局、消息发送
- 响应式测试：桌面(1440px)、平板(768px)、移动端(375px) 三个断点

## 风险与缓解

| 风险 | 缓解措施 |
|---|---|
| 内联样式硬编码颜色值较多，遗漏替换 | 使用 Grep 全局搜索 `#3B82F6`、`#2563EB` 等旧色值确保无遗漏 |
| 呼吸动画更新可能影响性能 | 保持 `prefers-reduced-motion` 媒体查询兼容 |
| Dashboard 布局大改可能影响响应式 | 保持现有 flex/grid 结构，仅调整内部元素 |
| 登录页样式与主应用风格差异 | 仅同步品牌色，不改动登录页布局逻辑 |
