🎯 项目核心功能概览

🤖 Agent 智能体层

Main Crew: 主任务编排器，负责意图理解与任务拆解
Sub-Crew: 子任务执行器，执行具体 Skill
Hook 框架: 9 大防御策略，YAML 声明式配置驱动

💾 三层记忆系统

L19 上下文压缩: 短期记忆，防止 token 溢出
L20 文件持久化: 中期记忆，保存偏好/SOP/事实
L21 向量搜索: 长期语义记忆 ⚠️ 当前未启用

🌐 前端 Web UI

13 个组件: Dashboard + 对话界面 + 管理后台
技术栈: React 19 / TypeScript / Vite 6
⚠️ App.tsx 单文件 62KB，需拆分优化

🔌 双入口接入层

飞书 WebSocket: 生产环境原生体验，低延迟推送
TestAPI HTTP: 开发调试接口，独立部署支持
共享 Runner + Crew 架构，避免重复实现

📊 数据持久层

6 张核心表: memories / conversations / sessions / skills
PostgreSQL + pgvector 向量扩展
ElectricSQL 实时同步到前端

🛡️ 安全与可观测性

Langfuse Trace: 完整 LLM 调用链路追踪
Prometheus Metrics: 关键指标监控
结构化日志: JSON 格式，便于 ELK 采集

🚨 安全风险评估（重要！）

🔴 CRITICAL - P0-1：敏感信息明文泄露（必须立即修复）

位置：.env 和 config.yaml 中包含明文 API Key 和 Secret
泄露内容：
• DEEPSEEK_API_KEY=sk-****（已脱敏）
• FEISHU_APP_SECRET=****（已脱敏）
风险：DeepSeek 账户被盗用产生高额费用 + 飞书应用被恶意操控
修复方案：
1. ✂️ 立即撤销上述所有密钥
2. 使用 git filter-repo 清理 Git 历史
3. 添加 .gitignore 规则排除敏感文件
4. 改用环境变量或密钥管理系统

🟠 HIGH - P0-2：TestAPI 生产模式开启（尽快修复）

现状：debug.enable_test_api: true
风险：弱 Token（test-token-dev-2024），容器端口映射后可能暴露到外网
方案：生产环境默认关闭（${XIAOPAW_TEST_API_ENABLED:-false}），通过环境变量显式开启

🟡 MEDIUM - 应该改进

• RBAC 权限粒度缺失：permission_gate 配置为空，无用户角色区分
• 沙箱逃逸风险：sandbox_guard 仅检查工具名前缀，缺乏命令注入检测
